# 🔥 Ember & Iron - Grill & Smokehouse Website

A responsive, high-performance website for **Ember & Iron Wood-Fired Smokehouse & Grill**.

## 🚀 How to Run Locally

### Option 1: Double Click (Easiest)
Simply double-click the **`start-server.bat`** file in this folder.

### Option 2: Terminal / Command Prompt
Run:
```bash
node server.js
```
or
```bash
npm start
```

Then open your browser and navigate to:
👉 **[http://localhost:3000](http://localhost:3000)** (or the port displayed in the console, e.g. `3001`).

---

## 📁 Project Structure

- **`index.html`** - Main homepage structure (Hero, Specialties, Interactive Menu, Story, Reviews, Table Booking, Footer).
- **`styles.css`** - Steakhouse dark aesthetic theme, typography, animations, and responsive layout.
- **`script.js`** - Dynamic menu filtering, interactive tasting cart, table reservation handler, and UI interactions.
- **`server.js`** - Lightweight, zero-dependency Node.js HTTP server.
- **`start-server.bat`** - One-click starter script for Windows.
- **`package.json`** - NPM configuration and commands.

---

## ✨ Key Features
- **Responsive Design**: Flawless experience on desktop, tablet, and mobile.
- **Interactive Tasting List**: Guests can select dishes to build a custom tasting order.
- **Table Reservation Engine**: Interactive booking with date, time, seating preferences, and instant confirmation modal.
- **Zero Dependencies Needed**: Runs immediately using standard Node.js.
